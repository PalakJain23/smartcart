# Customer Segmentation using K-Means

This project explores customer segmentation with unsupervised machine learning. The analysis is written in a Jupyter Notebook.

## Workflow

1. Clean the customer data and handle outliers.
2. Encode categorical features.
3. Apply PCA for dimensionality reduction and visualization.
4. Use the Elbow Method and Silhouette Score to compare cluster counts.
5. Apply K-Means to group customers with similar characteristics.

## Tools

Python, Jupyter Notebook, pandas, scikit-learn, Matplotlib, and kneed.

## How to run

1. Clone this repository.
2. Install the packages used in the notebook.
3. Place the dataset at the path expected by the notebook.
4. Open the `.ipynb` file in Jupyter Notebook and run the cells in order.

The dataset must be available for the notebook to run. If it cannot be shared, update the notebook or README with instructions for obtaining it.
